# Open Questions (the inbox)

> The **only** file anyone may freely append to. Drop a one-liner the moment a question or
> "actually we need this" occurs — don't break your flow. The spec owner triages in batches;
> resolved items move to an entry in `decisions.md` and the owning doc is updated
> (the change protocol: [`00-INDEX.md`](00-INDEX.md) §4).

## Format

`- OQ-NNN: <question> (where it came up, <date>) [behavior | presentation | undecided]`

- **behavior** → will become a product-spec / api-contract change with a stable ID
- **presentation** → likely ui-requirements / design-system only
- **undecided** → triage will classify it

Numbers are append-only; take the next free one (list this file first — parallel tracks collide).
